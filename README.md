# ProjetoJava

Desenvolvimento de um programa utilizando interface gráfica para a criação de uma Exchange de Criptomoedas, ou seja, uma plataforma onde é possível comprar e vender criptomoedas, nesse caso, Bitcoin, Ethereum e Ripple. Nesse programa deve haver as seguintes operações:

1. Efetuar login: O usuário deve informar CPF e senha para ter acesso as outras opções que serão listadas a seguir.

2. Consultar saldo: O usuário deve informar senha para que as informações de seu saldo pessoal atualizadas.

3. Consultar extrato: O usuário deve informar senha para que o histórico de operações seja exibido.

4. Depósito: O usuário informa o valor do depósito e o sistema atualiza o saldo.

5. Saque: O usuário informa o valor do saque, onde o valor não pode se tornar negativo, e o sistema atualiza o saldo.

6. Compra de criptomoedas: O usuário deve informar senha para ter acesso às cotações das criptomoedas e permite suas compras perante a taxa de compra.

7. Venda de criptomoedas: O usuário deve informar senha para ter acessoas cotações das criptomoedas e permite suas vendas perante a taxa de venda.

8. Atualizar cotação das criptomoedas: Utiliza da geração de números aleatórios para variar a cotação das criptomoedas, sendo de no máximo +5% e no mínimo -5%.
